🎬 Transcode Pipeline Demo

This demo shows the new streaming utilities in webcodecs-utils for building production-ready transcoding pipelines with WebCodecs + MediaBunny. 

// Clean, composable pipeline with automatic backpressure
const demuxer = new SimpleDemuxer(file);
await demuxer.load();

const muxer = new SimpleMuxer({ video: 'avc' });

await demuxer.videoStream()
  .pipeThrough(new VideoDecodeStream(config))
  .pipeThrough(new VideoProcessStream(processFn))
  .pipeThrough(new VideoEncodeStream(config))
  .pipeTo(muxer.videoSink());

const blob = await muxer.finalize();
