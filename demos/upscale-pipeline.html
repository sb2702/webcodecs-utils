🎨 Video Upscaling Pipeline Demo

This demo shows real-time AI video upscaling using WebSR + WebCodecs streaming pipeline. The video is upscaled from 320x180 to 640x360 using neural networks running in WebGPU. 

// Real upscaling with WebSR in the pipeline
const websr = new WebSR({ resolution, network, weights, gpu, canvas });

await demuxer.videoStream()
  .pipeThrough(new VideoDecodeStream(config))
  .pipeThrough(new VideoProcessStream(async (frame) => {
    await websr.render(frame);  // AI upscaling with WebGPU
    return new VideoFrame(canvas, { timestamp: frame.timestamp });
  }))
  .pipeThrough(new VideoEncodeStream(config))  // 2x resolution
  .pipeTo(muxer.videoSink());
